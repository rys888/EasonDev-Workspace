# 背景音乐（Background Music）

本目录中的原始背景音乐文件（`exile.mp3`）**因版权原因未包含在本仓库中**，也**不会随本仓库分发**。

- 站点代码（`src/components/RoomScene.tsx`）仍按 `/assets/audio/exile.mp3` 引用该文件。
- 该文件缺失时，播放器会**静默降级**（不播放、不报错），页面其余功能不受影响。
- 若你想在本地完整运行音乐功能，请**自行准备你有权使用的音频文件**，并按上面的路径放置。

> **版权声明**：本仓库不提供任何受版权保护的音乐。**请勿**将未经授权的声音文件提交到本仓库。
